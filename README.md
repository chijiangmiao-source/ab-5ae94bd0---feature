# 单细胞靶向测序矩阵 · 无限位点完美谱系补全

在浏览器中对含未知突变（`?`）的 0/1 单细胞矩阵做**可复算的精确补全**：

- 约束（无限位点 / infinite sites）：任意两列（突变）不得在细胞中**同时**出现
  `11`、`10`、`01` 三种配型 —— 等价于任意两个突变的载体集合互不相交或存在包含关系。
- 目标：在所有可行补全中**精确最小化问号补值的总代价**（代价为非负整数，**任意精度**）。
- 计算全部在浏览器本地 **Web Worker** 中完成，不阻塞页面、不上传数据。

## 规模约束

| 项 | 范围 |
| --- | --- |
| 细胞数（行） | 4 – 18 |
| 唯一突变数（列） | 3 – 12 |
| 未知格（`?`）总数 | ≤ 28 |
| 每个问号的代价 | 两个非负整数：填 0 代价、填 1 代价（位数不限，BigInt） |

## 结果含义

- **最小补值总代价** / **最优补全数**：均为任意精度整数（BigInt，十进制显示）。
- **规范补全矩阵**：在所有最优补全中，按**行优先、0 优先**裁决出的唯一代表矩阵。
- **每个问号的裁决**：
  - `固定 0`：所有最优补全中该格都是 0；
  - `固定 1`：所有最优补全中该格都是 1；
  - `同优可变`：取 0 或取 1 都能达到最优（计数中两种补全都存在）。
- **规范克隆树**：由补全后突变载体集合的包含关系（层状族）生成；空突变单列说明。
- **固定数据已三配型冲突**：直接给出涉及的突变对与三项细胞见证（11 / 10 / 01 各至少一行）。
- 规模或格式错误时只提示并**保留草稿**，不会用旧结果冒充新输入的答案（任何编辑都会立即隐藏旧结果）。
- “可复算记录”给出**输入 + 结果的 JSON**，可复制后重新核对。

## 算法要点（不枚举保存全部完成矩阵）

`src/solver.js`：

1. 先检测固定数据自身的三配型冲突（给出全部冲突对与见证行）。
2. 按“可能形成三配型”的列依赖图分解为连通分量，分别精确求解后合并（代价相加、计数相乘）。
3. 分量内用**层状包含森林的记忆化 DP**：每放入一列，其载体只能挂在森林的某个节点下
   （打包若干子树 ∪ 自身区域的子集），结构枚举而非 `2^u` 暴力；用
   `(min,+)` 半环聚合计数，同代价仅保留行优先 0 优先的唯一规范代表。
4. 配合贪心初始上界、可采纳下界剪枝与 MRV，28 未知格最坏情形在浏览器线程内毫秒级完成。
5. 只保存每状态的**聚合**（最小代价、计数、边际取 1 次数、一个规范代表），
   **不枚举、不保存**全部完成矩阵。

## 本地开发与运行

```bash
npm install
npm run dev       # 开发服务器
npm test          # 求解器单元测试（含暴力枚举对照）+ jsdom UI 端到端测试
npm run build     # 生产构建到 dist/
npm start         # 托管 dist/（端口可用 HOST_PORT 覆盖，默认 8080）
```

健康检查：`GET /healthz`。

## Docker / Compose

构建生产镜像（Vite 构建 + 精简 Node 静态服务器）：

```bash
# 常驻页面，宿主端口可配置
HOST_PORT=9090 docker compose up --build web
# 访问 http://localhost:9090/ ，健康检查 http://localhost:9090/healthz
```

一次性 verify 服务（**求解器测试 → 固定歧义/冲突样例核对 → 生产构建 → HTTP 冒烟**，
以退出码结束，0 表示全部通过）：

```bash
docker compose up --build verify
echo $?
```

不使用 Compose 时等价的本地命令：

```bash
sh verify.sh
```

`HOST_PORT` 控制常驻服务的宿主端口；`verify` 内部冒烟端口由 `SMOKE_PORT` 控制。

## 目录结构

```
src/solver.js     精确求解器（校验 / 冲突 / 层状森林 DP / 规范矩阵 / 克隆树）
src/worker.js     Web Worker 包装（BigInt 序列化为字符串）
src/main.js       页面状态、输入编辑、Worker 编排、结果/冲突/树渲染
index.html        页面
server.mjs        生产静态服务器（可配置端口 + /healthz）
scripts/
  verify-samples.mjs  固定歧义与冲突样例的显式断言
  smoke.mjs           HTTP 冒烟（健康路径、首页、JS/CSS/Worker chunk、路径穿越）
test/             node:test 单元测试（含 300+ 组随机暴力枚举对照与 UI 端到端）
verify.sh         一次性校验链
Dockerfile, docker-compose.yml
```
